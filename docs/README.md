## 📝 Documentation Conventions

### Code Blocks

- **Bash commands**: Prefixed with `$` or shown in code blocks
- **API requests**: Shown as cURL commands
- **Configuration**: YAML or properties format
- **Code examples**: Java with full context

### Symbols

- ✅ Recommended approach
- ❌ Not recommended
- ⚠️ Warning or important note
- 💡 Tip or best practice
- 🔧 Configuration required
